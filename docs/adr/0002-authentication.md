# Admin Authentication

The frontend and API require an authenticated admin before Ads, Recipients, email sending, or Refresh operations are available.

## Key decisions

- **Bearer tokens** are issued by `POST /auth/login` and validated on every protected request. The token is signed with HMAC-SHA256 and expires after eight hours by default.
- **PBKDF2-SHA256 password hashes** are stored instead of plaintext passwords. The first local credential is generated by `scripts/generate_admin_credentials.py`.
- **Local configuration file or environment variables** are supported. The generated `backend/data/auth.json` is ignored by Git; production deployments should use `ADMIN_USERNAME`, `ADMIN_PASSWORD_HASH`, and `AUTH_SECRET` environment variables.
- **Session storage in the frontend** keeps the bearer token scoped to the browser tab and avoids persisting an admin session indefinitely.
